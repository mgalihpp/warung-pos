Struktur Navigasi

Warung Sembako POS — Diagram Struktur Navigasi untuk Penelitian Ilmiah

1. Linear Navigation Sequential

Pengguna mengikuti alur langkah demi langkah secara berurutan. Tidak ada cabang atau loncatan ke halaman lain. Contoh: proses checkout POS dan alur autentikasi.

graph LR A[Login] --> B[Register] B --> C[Dashboard] D[POS - Pilih Barang] --> E[Keranjang] E --> F[Pembayaran] F --> G[Selesai / Nota]

2. Non-Linear Navigation Network

Setiap halaman dapat diakses dari halaman mana pun tanpa urutan tetap. Pengguna memiliki kebebasan penuh menjelajah. Contoh: tujuh menu utama Admin.

graph TD D[Dashboard] --- K[Kasir / POS] D --- B[Barang] D --- KT[Kategori] D --- T[Transaksi] D --- L[Laporan] D --- P[Pengaturan] K --- B K --- T B --- KT T --- L L --- P P --- K

3. Hierarchical Navigation Tree

Struktur pohon dengan hubungan parent-child. Navigasi dilakukan dengan turun ke sub-level atau naik ke level di atasnya. Contoh: tab Laporan, Pengaturan, dan Barang.

graph TD Admin[Admin Panel] --> D[Dashboard] Admin --> K[Kasir / POS] Admin --> B[Barang] Admin --> KT[Kategori] Admin --> T[Transaksi] Admin --> L[Laporan] Admin --> P[Pengaturan] Admin --> PG[Pengguna - Rencana] K ==> K1[Pilih Barang] K1 ==> K2[Keranjang] K2 ==> K3[Pembayaran] K3 ==> K4[Selesai] B --> BD[Daftar Barang] B --> BT[Tambah Barang] B --> BE[Detail Barang] BE --> BEE[Edit Barang] KT --> KTT[Tambah Kategori] KT --> KTE[Edit Kategori] T --> TD[Detail Transaksi] TD --> TDE[Edit Transaksi] L --> LP[Penjualan] L --> LS[Lap. Stok] L --> LK[Lap. Kas - Rencana] L --> LKR[Lap. Kasir - Rencana] P --> PP[Profile] P --> PM[Manajemen Akun] P --> PTA[Tambah Akun] P --> PT[Tema]

4. Hybrid / Campuran Combined

Menggabungkan elemen linear, non-linear, dan hierarkis dalam satu arsitektur. Ini adalah struktur aktual dari Warung Sembako POS.

Ringkasan

Tipe Struktur Karakteristik Ada di Aplikasi
Linear Berurutan, satu arah Checkout POS, autentikasi
Non-Linear Bebas, semua terhubung Menu utama Admin & Cashier
Hierarkis Pohon, parent-child Laporan, Pengaturan, Barang
Hybrid / Campuran Gabungan ketiganya Keseluruhan aplikasi
